# Spam SMS/Email Classifier (Task 2)

## Problem
Classify SMS/email messages as spam or ham and explain which words triggered the prediction.

## Approach
- TF-IDF vectorization
- Logistic Regression model

## Results
- Accuracy: 0.9758
- Precision: 0.8961
- Recall: 0.9262
- F1 Score: 0.9109

## Outputs
- Confusion matrix
- Example predictions with trigger keywords
- Saved model

## How to Run
Run notebook.ipynb in Google Colab.
