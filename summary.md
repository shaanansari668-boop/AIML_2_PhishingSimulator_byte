This project implements a machine learning solution for spam SMS/email detection.

The model was trained, evaluated, and tested successfully using a TF-IDF + Logistic Regression pipeline on the SMS Spam Collection dataset (Accuracy: 0.9758, Precision: 0.8961, Recall: 0.9262, F1: 0.9109).
All required outputs such as metrics, plots, and predictions are included.

The project demonstrates end-to-end ML pipeline implementation, from text preprocessing through model training, evaluation, and per-message explainability.
